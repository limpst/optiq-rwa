# OptiQ-RWA

**RWA 기반 수익 + 크립토 데일리 옵션 오버레이 최적화**

토큰화 실물자산(RWA)으로 안정적인 기초 수익을 확보하고, 그 수익을 예산으로 삼아 손실 한도가 정해진 크립토 데일리(0DTE) 옵션 포지션을 최적화하는 사이드 프로젝트입니다.

> 상태: 🌱 초기 단계 (사이드 프로젝트, 비정기 진행)

---

## 핵심 아이디어

| # | 아이디어 | 요약 |
|---|---|---|
| 1 | 수익으로 사는 옵션 | RWA 이자만으로 데일리 콜을 매수해 원금은 지키고 상승 노출만 확보 |
| 2 | 이벤트 밤 선택 (QUBO) | 날짜 × 코인 × 행사가 후보 중 예산 안의 최적 조합 선택 |
| 3 | 프리미엄 수취 | RWA를 담보로 데일리 옵션을 매도(커버드콜·현금담보 풋)하고 꼬리위험을 관리 |
| 4 | 확률 보정 리스크 모델 | 모델이 예측한 ITM 확률과 실제 ITM 비율의 차이를 측정하고, 호가 차이를 반영한 회수율 산출 |
| 5 | 무기한선물 vs 옵션 시뮬레이션 | 같은 방향성 판단을 고배율 무기한선물(청산 위험)과 데일리 콜(손실 상한)로 실행해 비교 |

**MVP 범위:** 아이디어 1 + 2 + 4

## 로드맵

### Phase 0 — 셋업 (1–2주)
- [ ] 저장소 구조, 개발 환경(Python), 코딩 규칙
- [ ] 데이터 소스 확정: Deribit 공개 API (BTC·ETH·SOL 데일리 옵션), RWA 수익률 (토큰화 국채)

### Phase 1 — 데이터 파이프라인 (2–3주)
- [ ] 데일리 옵션 과거 데이터 수집: 중간가, 매수·매도 호가, 내재변동성, 결제가
- [ ] 기초자산 가격과 이벤트 캘린더(FOMC, CPI, 토큰 언락) 정리
- [ ] 데이터 품질 점검 및 저장 포맷(Parquet) 정리

### Phase 2 — 리스크 모델링 (3–4주)
- [ ] 행사가 거리(σ√T의 몇 배인지)별 ITM 확률: 모델 예측과 실제 비교
- [ ] 코인, 시간대, 내재변동성 구간, 이벤트 여부별 분해
- [ ] 1달러당 회수액(중간가 기준·매도호가 기준) 산출

### Phase 3 — 최적화 (3–4주)
- [ ] 이벤트 밤 선택 문제를 QUBO로 정식화 (예산 제약, 상관관계 페널티)
- [ ] 비교 대상(SA, 그리디, 매일 매수)과 성능 비교
- [ ] RWA 수익 예산 배분 규칙 정의

### Phase 4 — 백테스트 & 시뮬레이션 (2–3주)
- [ ] 워크포워드 백테스트 (거래비용과 호가 차이 반영)
- [ ] 무기한선물 레버리지와 데일리 옵션 시나리오 비교
- [ ] 결과 리포트·대시보드

### Phase 5 — 확장 (추후)
- [ ] 매도 전략(아이디어 3)과 꼬리위험 관리
- [ ] 스마트컨트랙트 볼트 프로토타입·프론트엔드 연동
